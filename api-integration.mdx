## API Integration Guide

Integrate Selfmade Ninja Academy's APIs to access course data, manage enrollments, and track learning progress programmatically.

<Steps>
  <Step title="Get API Access" icon="key">
    Register for an API key in your account settings.
  </Step>
  <Step title="Review Documentation" icon="book-open">
    Familiarize yourself with our API endpoints and data structures.
  </Step>
  <Step title="Test Integration" icon="code">
    Use our sandbox environment to test your integration before going live.
  </Step>
  <Step title="Deploy" icon="rocket">
    Launch your integrated application with production API access.
  </Step>
</Steps>

<Tabs>
  <Tab title="Courses API" icon="book-open">
    <CodeGroup tabs="curl,Python">
      ```bash
# Get all courses
curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://api.selfmadeninja.com/courses
      ```
      ```python
import requests

headers = {'Authorization': 'Bearer YOUR_API_KEY'}
response = requests.get('https://api.selfmadeninja.com/courses', headers=headers)
courses = response.json()
for course in courses:
    print(f"{course['title']}: {course['description']}")
      ```
    </CodeGroup>
  </Tab>
  <Tab title="Enrollments API" icon="user">
    <CodeGroup tabs="curl,JavaScript">
      ```bash
# Enroll in a course
curl -X POST \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"course_id": "123"}' \
  https://api.selfmadeninja.com/enrollments
      ```
      ```javascript
// Enroll user in course
const enrollmentData = {
  course_id: '123',
  user_id: '456'
};

fetch('https://api.selfmadeninja.com/enrollments', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify(enrollmentData)
}).then(response => response.json())
  .then(data => console.log('Enrollment successful:', data));
      ```
    </CodeGroup>
  </Tab>

## Integration Examples

| Use Case | Endpoint | Method |
|----------|----------|--------|
| List courses | `/courses` | GET |
| Get course details | `/courses/{id}` | GET |
| Enroll user | `/enrollments` | POST |
| Track progress | `/progress/{user_id}` | GET |

<CodeGroup tabs="Python,Java">
  ```python
# Progress tracking example
from selfmade_ninja import APIClient

client = APIClient(api_key='YOUR_API_KEY')
progress = client.get_user_progress(user_id='123')
print(f"Completed {progress['completed_modules']}/{progress['total_modules']} modules")
  ```
  ```java
// Java integration example
import com.selfmadeninja.APIClient;

APIClient client = new APIClient("YOUR_API_KEY");
JSONObject progress = client.getUserProgress("123");
System.out.println("Progress: " + progress.getInt("completed_modules") + "/" + progress.getInt("total_modules"));
  ```
</CodeGroup>
